# 🌱 Plant!p 패치노트 v2.3

Plant!p 버전 2.3 업데이트가 완료되었습니다. 이번 업데이트는 사용자 경험 개선을 위한 완전히 새로운 네비게이션 디자인과 서비스 안정성을 위한 중대한 버그 수정이 포함되어 있습니다.

## 🎨 주요 디자인 업데이트

- **새로운 하단 네비게이션 바 도입**
  - 기존의 상단 네비게이션에 의존하던 모바일 경험을 개선하기 위해, 5개의 주요 메뉴(도감, 상점, 홈, 대시보드, 설정)를 쉽게 접근할 수 있는 세련된 하단 네비게이션을 추가했습니다.
  - **플로팅 홈 버튼**: 중앙의 '식물 검색(홈)' 버튼을 돋보이는 플로팅(공중에 뜬) 스타일의 원형 버튼으로 디자인하여 가장 중요한 기능에 대한 접근성을 극대화했습니다.
- **스타일 캐시 무효화 적용**
  - 디자인 업데이트 시 사용자의 브라우저에 이전 캐시가 남아 스타일이 깨지거나 안 보이는 현상을 완벽히 방지하도록 캐시 무효화(Cache Busting)를 적용했습니다.

## 🛠 버그 수정 및 안정성 개선 (Critical Fixes)

- **도감 미등록 현상 완벽 해결**
  - 일부 환경(Supabase 원격 테이블이 없는 경우 등)에서 도감 저장 시 서버 오류(500)가 발생하던 문제를 해결했습니다. 이제 오류 발생 시 안전하게 로컬 메모리 DB로 폴백되어 기록이 유실되지 않습니다.
- **AI 검색 503/504 오류 및 멈춤 현상 수정**
  - Google Gemini API 서버 과부하로 인해 검색이 중단되던 현상을 해결했습니다.
  - 안정성이 검증된 모델들(`gemini-3.1-flash-lite` 등)을 우선적으로 순차 폴백하도록 재배치하였습니다.
  - 만약 모든 AI 모델이 응답 불능 상태에 빠지더라도, 서버가 다운되지 않고 즉각적으로 **안전장치용 기본 식물 데이터**를 생성하여 응답하도록 2중 안전 장치를 구현했습니다.

## 🚀 배포 준비 가이드

성공적인 v2.3 배포를 위해 다음 사항들을 확인해 주세요.

1. **환경 변수 확인**
   - `.env` 파일의 `DEV_MODE=false`로 설정되어 있는지 확인하세요.
2. **도커 빌드 (Docker Build)**
   ```bash
   docker build -t plant_wiki:v2.3 .
   ```
3. **도커 실행 (Docker Run)**
   ```bash
   docker run -d -p 8000:8000 --env-file .env plant_wiki:v2.3
   ```
4. **Supabase 스키마 (선택 사항)**
   - 아직 Supabase에 `plant_history`, `profiles` 테이블 생성을 완료하지 않으셨다면 대시보드 SQL 에디터에서 테이블을 생성하시거나, 현재처럼 인메모리(Memory DB) 폴백 모드를 유지하시면 됩니다.
