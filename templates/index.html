📜 패치노트 — Plant!p 버전별 업데이트 기록

🚀

[Alpha 1.0] "한 걸음의 시작" Original

터미널 가상화 에러와 꼬인 구글 API 키 족쇄를 뚫고, 순수한 파이썬 백엔드 환경에서 최초의 식물 데이터 매칭 서버 초안을 빌드하는 데 성공한 전설의 오리지널 버전.

🌿

[Alpha 1.1] "세로형의 진화" Transition

오픈코드 에이전트와 교감하며 사용자 편의성을 높이기 위해 좌측 고정식 '그린 세로 사이드바 UI'와 SQLite 3 관계형 데이터베이스 도감 저장 시스템을 최초로 융합시킨 과도기적 빌드.

🌌

[Beta 1.0] "AI 포털의 탄생" Archived

사이드바를 과감히 부수고 챗GPT 스타일의 중앙 포털 레이아웃 도입! 사용자가 식물을 검색하면 로고가 상단으로 슬라이드 업되는 영화 같은 트랜지션 모션과 웹상의 뜬소문을 수치화해 검증하는 'AI 상식 정확도 찬/반 띠 그래프' 파이프라인을 최종 완성한 완전체 마스터피스 버전.

☁️

[Beta 2.0] "클라우드의 날개" Cloud

로컬 SQLite를 완전히 걷어내고 수퍼베이스(Supabase) 원격 클라우드 DB로 도감을 이전! 로그인한 유저의 검색 기록이 실시간 원격 저장되고 📚 나의 도감에서 본인 데이터만 타임라인으로 펼쳐져요. 비식물 검색어를 막아주는 🌱 식물 가드레일도 함께 탑재된 업그레이드 버전.

🍃

[Beta 2.1] "리프와 연속학습의 새싹" Gamification

Google 원클릭 간편 로그인과 유저 프로필 시스템 탑재! 출석체크로 매일 🔥 연속학습 스트릭을 쌓고 🍃 리프 화폐를 모아 나만의 식물 정원을 꾸밀 준비를 마친 하이브리드 게이미피케이션 업데이트.

💧

[Beta 2.2] "대시보드와 스마트 케어" Dashboard

나만의 반려식물 건강을 한눈에 파악하는 📊 대시보드 뷰 신설! 식물별 물주기 알림 관리, 오전 9시 이메일 발송 자동화, 그리고 내 라이프스타일에 딱 맞는 반려식물을 찾아주는 🌱 3초 식물 MBTI 퀴즈 시스템 구축.

📱

[Beta 2.3] "하단 네비게이션과 무중단 안정성" Architecture

모바일 경험 극대화를 위한 중앙 플로팅 FAB 5탭 하단 네비게이션 바(도감, 상점, 홈, 대시보드, 설정) 탑재! Gemini API 과부하 시 모델 순차 폴백 및 Supabase 연결 장애 시 무중단 인메모리 자동 폴백 안전망 완성.

이조익(Ezoic)으로 실제 수익을 극대화하는 4단계 핵심 가이드:
1. 도메인 연결: plantwiki.kro.kr(또는 개인 .com/.kr 도메인)의 소유권을 인증합니다.
2. Ezoic 무료 가입: 'Access Now' 프로그램은 방문자수 제한(구 1만 명 조건 폐지) 없이 신규 사이트도 즉시 신청 가능합니다.
3. Cloudflare / 네임서버 연동: Ezoic 네임서버를 Cloudflare에 연동하면 Leap 기능으로 사이트 속도가 2배 빨라지고 광고 단가(EPMV)가 상승합니다.
4. ads.txt 등록: Ezoic 승인 후 발급받은 ads.txt 코드를 아래 에디터에 붙여넣고 저장하면 즉시 /ads.txt로 전 세계 광고 입찰이 시작됩니다.
